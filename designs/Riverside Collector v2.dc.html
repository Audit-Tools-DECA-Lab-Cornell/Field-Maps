Map behaviour
Navigating and marking are separate modes
Tapping the map selects things on it. Placing an observation is a mode you arm first, so panning with a gloved thumb can never drop a point by accident. Prior observations cluster into a single count when zoomed out and separate as you zoom in.
The base map is subdued so the data reads first. Markers carry a dark halo and a light ring, so they hold up on both the plan and the aerial. The form panel collapses when the map needs the whole screen.

Tap the map before arming — nothing is placed.
Zoom out to 1× and the four prior observations become one cluster.
Switch to the aerial and watch the markers keep their contrast.
Collapse the panel, then answer loose parts Yes and set it back to No.
